PERSONALIZAR PERFILES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Edita: mcp/src/server.js
2. Busca: const PROFILES = {
3. Agrega tu perfil:

   'mi-app': {
     projectKey: 'mi-app-key',
     projectName: 'Mi App',
     sources: ['src', 'app'],
     exclusions: ['**/*.test.js'],
     language: 'js',
   }

4. Guarda y reinicia:
   - Ctrl+C en la terminal de start.sh
   - ./start.sh

SOLUCIÓN DE PROBLEMAS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

❌ "Connection refused" en localhost:9000
   → Ejecuta: ./start.sh
   → Espera 40 segundos
   → Verifica: docker ps | grep sonarqube

❌ "sonar-scanner: command not found"
   → Instala: brew install sonar-scanner
   → Verifica: sonar-scanner --version

❌ "Port 9000 already in use"
   → Ver proceso: lsof -i :9000
   → Matar proceso: kill -9 <PID>
   → O cambiar puerto en docker-compose.yml

❌ MCP no responde (curl: (7) Failed to connect)
   → Verifica: curl http://localhost:3001/health
   → Revisa logs: Busca errores en la terminal de start.sh
   → Reinicia: Ctrl+C en start.sh, ./start.sh nuevamente

❌ Permisos denegados en los scripts
   → Hazlos ejecutables:
     chmod +x *.sh examples/*.sh

COMANDOS ÚTILES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

$ docker ps | grep sonarqube

$ docker-compose restart sonarqube

Ver volúmenes:
$ docker volume ls | grep sonarqube

Limpiar todo (perder datos):
$ docker-compose down -v
