🔄 FLUJO DE INICIALIZACIÓN
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. ./start.sh
   ├─ Verifica Docker ✓
   ├─ Verifica sonar-scanner ✓
   ├─ docker-compose up -d
   │  └─ Inicia SonarQube (puerto 9000)
   ├─ Espera a que esté listo (~40s)
   └─ node mcp/src/server.js
      └─ Inicia MCP (puerto 3001)

2. Acceder a:
   ├─ http://localhost:9000       (SonarQube UI)
   ├─ http://localhost:3001/health (MCP Health)
   └─ http://localhost:3001/profiles (Perfiles disponibles)

3. Escanear proyecto:
   ├─ Opción A: Perfil preconfigurado
   │  └─ bash examples/scan-backend.sh
   └─ Opción B: Dinámico (cualquier proyecto)
      └─ curl POST /scan-dynamic

4. Ver resultados:
   └─ http://localhost:9000/dashboard?id=PROJECT_KEY
